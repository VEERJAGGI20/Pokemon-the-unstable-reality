# Pokémon: The Unstable Reality — Graphics

The approved master graphics sheet is the visual direction for **Pokémon: The Unstable Reality**.

The game uses a restrained, polished GBA pixel-art direction with environmental discipline inspired by later 2D Pokémon presentation:
- low-to-moderate saturation
- clean, deliberate pixel clusters
- readable silhouettes
- layered depth instead of glow
- natural greens, browns, greys and controlled blues
- subtle atmospheric variation
- no neon fantasy-RPG clutter

The master sheet is a reference board, not a directly importable tileset. Production assets must be extracted/redrawn into GBA-compatible tiles, palettes and metatiles.

## Production asset #1: title logo

The FRLG title-logo slot now contains an original **Pokémon: The Unstable Reality** title treatment sized to the native 256×64 logo canvas. The same source is kept for FireRed and LeafGreen builds so branding does not drift between targets.

Internal shorthand such as `UO` may appear in developer paths/docs, but the player-facing game name is always **Pokémon: The Unstable Reality**.
