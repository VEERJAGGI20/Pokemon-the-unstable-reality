# Title Logo Integration

The FireRed and LeafGreen FRLG title-logo source slots use the same 256×64 indexed PNG for consistent branding.

The logo is intentionally restrained so the title screen remains readable on original GBA-scale output.

Before release, run the normal expansion graphics build and inspect the rendered title screen in mGBA. The title-map layout is inherited from the FRLG base and should be visually checked after compilation.
